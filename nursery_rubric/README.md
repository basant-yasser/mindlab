# Nursery Rubric Assessments (Odoo 19)

Add-on provides rubric templates and student assessments with weighted scoring and PDF reporting.

## Installation
1. Copy folder `nursery_rubric` into your Odoo addons path.
2. Update Apps list.
3. Install "Nursery Rubric Assessments".

## Usage
- Create a Rubric in: Nursery > Rubrics
- Create an Assessment in: Nursery > Assessments
- Selecting a Rubric auto-generates rubric lines.
- Print: Assessment Report
